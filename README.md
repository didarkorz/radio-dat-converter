# Radio DAT Converter

Конвертер настроек каналов рации из старого DAT-файла в формат нового CPS (Customer Programming Software — ПО для настройки радиостанций).

## Зачем появился проект

Старые рации настраивались через своё ПО. После появления новой модели и нового ПО сохранённый файл настроек перестал подходить: перенести конфигурацию привычным способом не получалось.

По воспоминаниям автора, задача возникла при работе с рациями **WLN KD-C1**. Точные обозначения старой и новой модификаций не сохранились; возможное различие в буквах `T` и `C` требует уточнения. Названия и версии использованного ПО также пока не установлены.

Для решения этой задачи был написан Python-скрипт, который читает каналы из старого файла и записывает их в структуру файла, сохранённого новым ПО. Это позволяет подготовить конфигурацию для открытия в новом CPS без ручного ввода частот и тонов каждого канала.

В этом проекте обрабатывается **файл конфигурации каналов**. Скрипт не изменяет исполняемую прошивку и не записывает данные в рацию напрямую.

## Возможности

- Перенос до 16 каналов с сохранением порядка.
- Перенос частот приёма (RX) и передачи (TX).
- Перенос тонов CTCSS, кодов DCS и значения `OFF`.
- Преобразование одного флага канала по наблюдаемому соответствию старого и нового форматов.
- Сохранение данных шаблона за пределами заменённых записей каналов.
- Обратное чтение результата и проверка частот и тонов через `--report`.
- Работа без сторонних Python-библиотек.

## Быстрый запуск

Требуется Python 3.9 или новее. Выполняйте команды из папки проекта.

### Окно для ввода и конвертации

В Windows дважды нажмите `start_gui.bat` или выполните:

```sh
python radio_gui.py
```

1. Нажмите **«Открыть старый DAT…»** и выберите исходный файл. Если рядом со скриптом есть `123.dat`, он загрузится при запуске.
2. Выберите **шаблон нового ПО**. Локальный `124.dat`, если он есть, подставляется автоматически. Для проверки на примерах можно выбрать `examples/legacy.dat` и `examples/modern_template.dat`.
3. Выберите канал в таблице. Слева показаны исходные значения, справа — значения для нового файла.
4. Введите нужные частоты RX/TX и тоны, затем нажмите **«Применить»**. Текущий ввод также применяется при переключении канала и сохранении. Изменённые строки выделяются цветом.
5. Нажмите **«Сохранить DAT»** вверху окна или **Ctrl+S** и выберите имя и папку для готового DAT. После сохранения справа будут показаны значения, прочитанные обратно из результата; путь к файлу появится внизу окна. Повторное сохранение записывает изменения в выбранный файл. Для отдельной копии нажмите **«Сохранить как…»** или **Ctrl+Shift+S**.

Можно вводить каналы вручную кнопкой **«Добавить канал»**, без старого файла. Шаблон нового ПО всё равно нужен. Максимум — 16 каналов. У добавленных вручную каналов используется флаг `EB`; у загруженных сохраняется соответствие флага исходнику. Кнопка **«Убрать последний»** удаляет последнюю строку из списка в окне; исходный файл не изменяется. Оставшиеся записи в шаблоне сохраняются, поэтому уменьшение списка не очищает лишние каналы шаблона.

Частоты вводятся в МГц: `435.32500`, `435.325` или `435,325`. Тоны: `OFF`, `127.3`, `D371N`, `D371I` (также принимается `D371R`, который нормализуется в `D371I`). Изменение формата файла само по себе не меняет частоты: новые значения будут отличаться только после вашего редактирования.

Окно использует `tkinter`, который входит в обычную установку Python для Windows. Если модуль отсутствует, добавьте компонент Tcl/Tk через установщик Python.

### Командная строка

Проверить конвертацию на комплекте примеров:

```sh
python convert_dat.py --old examples/legacy.dat --template examples/modern_template.dat --output converted.dat --report
```

Результат появится в `converted.dat`. В терминале будет таблица каналов:

```text
Channel  RX         TX         RX Tone  TX Tone  Flag
-------  ---------  ---------  -------  -------  ----
      1  435.32500  435.32500  127.3    127.3    EB
      2  436.43500  436.43500  D371N    D371N    EF
      3  437.66500  437.66500  OFF      OFF      EB
```

Частоты в примерах служат для проверки преобразования формата.

## Работа со своими файлами

1. Сохраните исходную конфигурацию из старого ПО.
2. Сохраните файл-шаблон через новое ПО для целевой рации. Он должен соответствовать поддерживаемой структуре, описанной в [документации формата](docs/FORMAT.md).
3. Запустите конвертер, указав пути к исходнику, шаблону и результату:

   ```sh
   python convert_dat.py --old old.dat --template template.dat --output new.dat --report
   ```

4. Откройте результат в новом CPS и проверьте параметры каналов и общие настройки перед записью в рацию.

Выходной файл перезаписывается, если уже существует. Используйте отдельный путь для результата.

| Аргумент | Назначение | По умолчанию |
| --- | --- | --- |
| `--old` | Старый файл с каналами | `123.dat` |
| `--template` | Файл нового формата | `124.dat` |
| `--output` | Результат конвертации | `123_converted.dat` |
| `--report` | Вывести и проверить частоты и тоны результата | Выключен |

Имена по умолчанию сохранены для совместимости с первоначальным рабочим процессом. В репозитории примеры находятся в `examples/`, поэтому для них используются явные аргументы, как в быстром запуске.

## Проверка

```sh
python -m unittest discover -s tests -v
```

Проверки сравнивают конвертацию с существующим эталоном, проверяют сохранение данных шаблона, поведение при неполном наборе каналов, запуск командной строки с отчётом, обработку ручного ввода и запись отредактированных значений. Аппаратная совместимость этими проверками не устанавливается.

## Совместимость и ограничения

- Реализация основана на конкретной паре файлов. В новом образце используется заголовок `[FSF008_Analog_Redio]`; он не подтверждает совместимость со всеми моделями раций.
- Контекст исходной задачи — WLN KD-C1 со слов автора. Точные модификации и версии CPS пока не установлены; совместимость со всей линейкой WLN KD-C1 и другими форматами DAT не заявлена.
- Из старого файла читаются первые строки каналов с 18 полями через запятую. Остальные старые настройки не переносятся: общие параметры берутся из нового шаблона.
- Если каналов меньше 16, оставшиеся каналы сохраняются из шаблона.
- Назначение переносимого флага не подтверждено: соответствие `1 → EB`, остальные значения `→ EF` восстановлено по примерам.
- Частоты ожидаются в виде `435.32500`, CTCSS — с одной цифрой после точки, например `127.3`. DCS поддерживает `N` и инверсные обозначения `I`/`R`; для `--report` используйте `I`, так как обратное чтение возвращает именно его и сравнение с `R` сообщит о несовпадении.
- `--report` проверяет частоты и тоны после записи файла. Он не проверяет смысл флагов, общие настройки или возможность загрузки в устройство.

Подробности структуры и принятых соответствий: [docs/FORMAT.md](docs/FORMAT.md).
